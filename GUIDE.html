Guide utilisateur

Prise en main complète de Ratio Spoof Manager, l'interface de bureau du moteur ratio-spoof.

Tauri 2 · Rust + Web Windows · macOS · Linux Moteur Go en sidecar

1Démarrage

Installation

Chaque release publie deux formes. Choisissez selon ce que vous voulez en faire.

Paquet portable (`.zip`)Installateur (`_x64-setup.exe`)
InstallationAucune : décompressez et lancezAssistant NSIS classique
Mise à jourL'application annonce la mise à jour ; accepter lance l'installateur NSIS, qui crée une copie installéeTéléchargement, vérification de signature, installation, redémarrage
Recommandé siVous voulez une copie autonome sur une clé USBVous voulez une installation classique dans le menu Démarrer
Le portable se décompresse en entier

L'application cherche le moteur à côté de son exécutable, puis dans son sous-dossier binaries\. Si vous déplacez ratio-spoof-manager.exe seul, le moteur devient introuvable — voir Dépannage.

Premier lancement

  1. Lancez ratio-spoof-manager.exe. La fenêtre s'ouvre avec un formulaire « Nouvelle session » à gauche, vide à droite.
  2. L'application vérifie en arrière-plan si une version plus récente est disponible. Un échec réseau passe inaperçu — ce n'est pas bloquant.
  3. Windows peut afficher une demande de permission pour les notifications : elle sert aux alertes de ratio et au redémarrage automatique. Refusée, l'application fonctionne quand même, sans notification.

2Le formulaire « Nouvelle session »

Le panneau de gauche se rétrécit ou s'élargit : attrapez la poignée centrale et faites glisser. Vous pouvez déposer un .torrent n'importe où dans la fenêtre.

Les cinq étapes

  1. Le fichier .torrent — glissez-déposez sur le cadre bleu, ou cliquez pour parcourir. Un jeton apparaît ensuite avec le nom du fichier ; la croix à droite l'enlève pour en choisir un autre.
  2. Télécharge / Vitesse DL — le volume que vous prétendez avoir téléchargé, et la vitesse correspondante.
  3. Uploade / Vitesse UL — le volume envoyé, et sa vitesse.
  4. Port et client — le port d'écoute et l'identité que le tracker attribue à votre client.
  5. Moteur — Intégré par défaut (le sidecar livré), ou Personnalisé pour pointer un autre binaire.

Chaque champ est validé au fil de la frappe : bordure verte et mention « OK » quand la saisie est exploitable. Les champs restent neutres tant que vous n'avez rien tapé ; c'est le clic sur Lancer la session qui signale ce qui manque encore.

Les vitesses sont en deux morceaux

Un nombre dans le champ, l'unité (kbps ou mbps) dans le menu déroulant à côté. Taper 5mbps d'un bloc reste accepté : l'unité rejoint alors le menu. Ce sont les deux seules unités que le moteur comprend — gbps et bps sont refusés.

3Les champs en détail

Télécharge
Pourcentage ou taille : 100%, 50%, 500MB, 1.5GB. Unités acceptées : %, b, kb, mb, gb, tb (base 1024).
Vitesse DL
Nombre + unité. 0kbps signifie « aucun download » — c'est le réglage du preset Seed pur.
Uploade
Même syntaxe que Télécharge. 0% n'envoie rien : c'est le preset Leech.
Vitesse UL
Nombre + unité. C'est la valeur qui fait monter votre ratio.
Port
Entier de 1 à 65535. Doit être cohérent avec le port réellement utilisé par votre client réel si vousSeedez pour de vrai.
Client
Le Peer ID annoncé au tracker. qBittorrent 4.0.3, qBittorrent 4.3.3, ou ID personnalisé pour saisir une valeur libre (ex. QB4650).
Moteur
Intégré utilise le sidecar livré avec l'application. Personnalisé ouvre un sélecteur de fichier — utile pour tester un moteur compilé localement.

4Presets

Quatre presets sont fournis. Un clic remplit tout le formulaire ; les champs sont revalidés immédiatement.

Vos propres presets

Le bouton + Sauvegarder preset, sous la barre de presets, enregistre la configuration affichée. Donnez-lui un nom : il apparaît à côté des quatre autres et se sélectionne d'un clic.

La gestion se fait dans Paramètres → Presets personnalisés, où la croix à droite d'un nom le supprime. Ces presets sont stockés par l'application et survivent aux redémarrages.

Un preset ne mémorise pas le torrent

Il ne retient que les paramètres (volumes, vitesses, port, client). Il faut déposer le fichier .torrent à chaque fois.

5Suivre une session

Chaque session lancée devient une carte dans le panneau de droite, avec un point de statut coloré :

StatutSignificationActions disponibles
Demarrage...Le moteur se lance.—
En coursLe moteur tourne et annonce au tracker.Pause, Arrêter
En pauseInterrompu volontairement.Reprendre, Arrêter
Arret...Arrêt en cours — le moteur prépare sa dernière annonce.— (boutons figés)
ArreteArrêté proprement.Supprimer
ErreurLe moteur n'a pas pu démarrer.Supprimer

Ce que lit chaque carte

  • Upload — volume total envoyé
  • Vitesse UL — débit courant
  • Ratio — upload / download, une décimale
  • Temps — durée depuis le lancement
  • Graphique — débit d'upload, tracé uniquement quand la carte est visible
  • Barre de progression — avancement du téléchargement annoncé

Le champ de recherche filtre les sessions par nom. Le Journal en bas affiche la sortie brute du moteur de la session sélectionnée, colorée par niveau.

L'arrêt est propre, il ne coupe pas net

Au clic sur Arrêter, l'application envoie une interruption contrôlée : le moteur a le temps d'envoyer son annonce finale « stopped » au tracker. Si jamais il ne répond pas, il est tué au bout de 10 secondes. En cas de plantage de l'application elle-même, les moteurs rattachés sont tués automatiquement — aucun processus ne survit en announce fantôme.

6Statistiques globales

La barre sous l'en-tête agrège toutes les sessions, rafraîchie au rythme défini dans les paramètres (2 secondes par défaut) :

  • Sessions actives — nombre de sessions en cours
  • Upload total / Download total — cumul de toutes les sessions
  • Ratio moyen — rapport global upload/download

Le graphique « Upload global (24h) » trace le débit cumulé de toutes les sessions réunies.

Rafraîchissement automatique

Quand la fenêtre passe en arrière-plan, l'intervalle passe à 30 secondes pour économiser des ressources ; il revient à la valeur normale dès que vous rouvrez la fenêtre.

9Mises à jour

L'application vérifie la dernière release au démarrage, quelques secondes après l'ouverture. Si une version plus récente existe, elle annonce le numéro et propose l'installation ; votre réponse est demandée — rien ne s'installe en silence.

L'installateur téléchargé est vérifié par signature contre la clé publique figée dans le binaire avant toute exécution : un artefact altéré est refusé. Après installation, l'application redémarre d'elle-même.

Vous pouvez déclencher la vérification à tout moment via Paramètres → Vérifier une mise à jour.

En paquet portable

La même annonce apparaît. Accepter lance l'installateur NSIS, qui crée une copie installée à côté — le portable lui-même n'est pas modifié. Refuser le laisse intact, et la question vous sera reposée au démarrage suivant.

10À propos du binaire

Le bouton À propos de l'en-tête affiche quatre informations figées à la compilation :

  • Version — le numéro de livraison
  • Commit — le hash court du commit git, sélectionnable pour être copié
  • Date du commit
  • État des sources — indique si le binaire a été compilé depuis un dépôt propre ou modifié

Ces valeurs identifient la livraison qui tourne, indépendamment du dépôt éventuellement présent sur la machine. Si le binaire a été compilé hors dépôt (archive de sources), elles affichent « inconnu » — jamais une valeur fausse.

11Dépannage

« Renseignez les vitesses DL et UL »

Le champ nombre est vide. Saisissez un nombre et choisissez kbps ou mbps dans le menu déroulant à côté — l'unité n'est plus devinée.

« Nombre ou unité invalide »

Le moteur n'accepte que kbps et mbps, en base 1024. 1gbps, 500bps ou une lettre glissée sont refusés : passez par 1000mbps.

Une seconde fenêtre s'ouvre au lancement d'une session

Un exécutable nommé ratio-spoof traîne dans le dossier de l'application — un vieux moteur 2021 s'y est glissé. Supprimez-le ou déplacez-le : l'application cherche un fichier dont le nom ressemble à un target triple (ratio-spoof-x86_64-pc-windows-msvc.exe).

Le moteur est introuvable

Le dossier binaries\ n'est plus à côté de l'exécutable. Reprenez l'archive complète, ou indiquez le chemin via Moteur → Personnalisé dans le formulaire.

Le port est refusé

La plage valide est 1 à 65535. En pratique, évitez les ports inférieurs à 1024 : ils exigent des privilèges administrateur.

Les statistiques ne bougent pas

Vérifiez l'intervalle de polling dans les paramètres. Si une session affiche « Arret... » indéfiniment, le moteur ne répond plus : supprimez la session et relancez-la.

Aucune notification n'arrive

Windows a peut-être refusé la permission. Vérifiez dans les réglages système → Notifications que l'application est autorisée.

12Avertissement

Usage à vos seuls risques

N'utilisez ce logiciel que là où vous y êtes autorisé. Déclarer des volumes téléchargés ou envoyés qui n'ont pas été échangés peut violer les règles d'un tracker privé et entraîner la suspension du compte. Préférez le seed réel dès que possible.
